Входные данные
Учебные данные: 60 млн т/год, 330 дней, 24 ч/сут. Вводимые значения должны быть положительными; дни не больше 366, часы не больше 24.
Алгоритм
Прочитать поля → проверить числа и диапазоны → перевести млн т в т → разделить на дни и часы → округлить до одного знака → показать результат с единицами. При ошибке очистить прежний результат и показать причину.
Разработка
Создать один index.html со встроенными CSS и JavaScript без внешних библиотек. Вместе с Codex найти в коде ввод, проверку и расчёт; самостоятельно изменить подпись поля.
